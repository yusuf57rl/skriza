## About

Skriza is a European social network built around reputation instead of engagement. Content is ranked by discussion and replies rather than views, and accounts are verified, so that thoughtful contributions rise and noise does not.

- **Reputation-based ranking** with published ranking principles
- **Verified identities**, with university email and EU digital identity verification planned
- **European infrastructure** and a European legal venue
- **Youth protection** built in from the start
- **No surveillance advertising**, and your data is never sold

## Status

Skriza is under active development and currently in a **closed beta**. Testers are invited in small numbers; if you'd like to take part, apply on [skriza.com](https://skriza.com). The public launch follows once the European infrastructure is complete.

## About this repository

This repository is an archive. It holds the early open-source code that was published for Hacktoberfest 2023 and is **outdated**. It no longer reflects the current platform, whose development continues in a private repository. Thank you to everyone who contributed back then.
